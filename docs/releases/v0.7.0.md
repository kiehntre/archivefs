# ArchiveFS v0.7.0 release notes

ArchiveFS v0.7.0 is the stable promotion of the manually approved
`v0.7.0-rc.1` candidate. It combines evidence-based platform detection,
bounded disc identity, safer emulator-profile resolution, transaction-backed
cheat workflows, expanded Doctor diagnostics, and an optional browse-only
BSFree Archive source.

## Highlights

- One canonical registry contains 74 platforms and 311 explicit aliases.
  Detection reports `Confirmed`, `Probable`, `Ambiguous`, or `Unknown`, while
  `DetectionEvidence.conclusive` distinguishes structurally valid evidence
  from evidence that uniquely settles a platform.
- Trusted-root-aware signature reads can inspect safe in-root symlinks without
  allowing broken, looping, or escaping links.
- Bounded read-only Atari ST `.st` and Pasti `.stx` validation improves Atari
  ST identification without treating generic FAT12 structure as conclusive.
- Wii WBFS identity reads the embedded six-character Dolphin Game ID, disc,
  revision, and region evidence without trusting the filename.
- GameHacking workflows cover PS2, GameCube, and Wii. Browser-assisted Wii
  import supports partial offline caches; the validated SMNE01 page yields
  121 parsed entries, of which 98 are supported and 23 are blocked or unknown.
- Dolphin discovery supports Flatpak's data-tree profile and explicit
  AppImage/native `-u`, `--user`, and `--user=<path>` roots. Running and
  manually selected profiles are labelled separately.
- Doctor Stages 1A, 1B, and 1C-A add read-only setup/environment findings,
  narrowly bound safe repairs, and grouped historical mount results.
- The fixed-height Gamer View platform shelf supports Previous/Next, wheel,
  trackpad, drag, keyboard, and TV/Moonlight navigation.
- BSFree Archive is an optional third-party source with explicit download or
  local import, strict validation, immutable/query-only SQLite access, bounded
  browsing, provenance, and licence warnings. It remains browse-only.

## Manual approval

The `v0.7.0-rc.1` artifact was tested on the real Sunshine desktop and approved
for promotion. The pass verified:

- Gamer View shelf layout and navigation;
- Atari ST display behavior;
- BSFree reaching Ready and remaining browse-only; and
- absence of a BSFree Install action.

## Install

Keep the archive and adjacent checksum together, then run:

```sh
sha256sum -c archivefs-v0.7.0-x86_64-linux.tar.gz.sha256
tar -xzf archivefs-v0.7.0-x86_64-linux.tar.gz
cd archivefs-v0.7.0-x86_64-linux
./archivefs-cli --version
./install.sh
```

The installer is per-user, uses no `sudo`, and does not overwrite an existing
configuration. On first run, edit the generated configuration, validate it
with `archivefs-cli config-check`, run `archivefs-cli doctor`, then add or scan
sources explicitly. No source scan, provider download, cheat installation, or
emulator launch is automatic.

## Upgrade from v0.6

Stop ArchiveFS and back up the catalogue and managed state before upgrading.
v0.7 applies forward-only database migrations through schema 6; migrations are
exactly `0001` through `0006`. Existing source configuration, manual platform
assignments, remembered Dolphin choices, and cheat-source settings are
preserved. Older binaries cannot open schema 6, so rollback requires restoring
the pre-upgrade backup rather than editing SQLite metadata.

After upgrading, run:

```sh
archivefs-cli doctor --findings
archivefs-cli library-scan
```

A rescan is especially useful for platform findings stored before the
canonical registry and Atari ST detector were introduced.

## Useful commands

```sh
archivefs-cli --version
archivefs-cli platform-detect /path/to/game.st
archivefs-cli game-identity-inspect --path /path/to/game.wbfs --platform Wii
archivefs-cli doctor --findings --json
archivefs-cli cheats source bsfree status --json
archivefs-cli cheats source bsfree search --platform NES --title MARIO --json
```

BSFree download and import are explicit operations. Ordinary BSFree status,
search, and browsing do not install cheats or write emulator profiles.

## Safety and data ownership

- Archive, ROM, and disc-image sources remain read-only.
- Atari disk inspection is cancellable and bounded to 64 KiB total, 1 KiB per
  read, a 32 KiB maximum offset, a 4 MiB raw-image cap, and a 32 MiB STX cap.
- Supported emulator writes require explicit preview and confirmation, use
  atomic replacement and backups where applicable, and verify the live target.
- Cloudflare challenge pages are typed and never cached as provider content.
- BSFree is not bundled. Its historical database-content licence is not
  established, and ArchiveFS opens its local copy read-only/query-only.

## Known limitations

- BSFree remains browse-only and cannot install or convert codes.
- BSFree title/platform matching can return ambiguous versions or revisions;
  it does not establish exact ROM identity.
- ZIP-contained, CHD, RVZ, and generic BIN identity remains incomplete for
  some platforms and layouts.
- RomM provider integration is not included.
- Emulator-specific cheat writers remain limited to explicitly supported
  formats and destinations.
- Some stored historical platform findings require a rescan before they show
  the current classification.
- Malformed, cracked, padded, or loader-modified Atari ST `.st` images may
  remain Probable when their FAT12 geometry cannot be verified.
- Symlink signature scanning remains opt-in through trusted-root-aware paths.
